Project Overview

This Power BI dashboard analyzes employee attrition patterns and identifies key factors influencing workforce turnover. The objective is to help organizations understand attrition drivers and develop effective employee retention strategies.

Key Insights
Sales Representatives show the highest attrition rate (39.76%)
Employees working overtime have nearly 3× higher attrition
Employees aged 18–24 experience the highest turnover
Lower income bands show significantly higher attrition rates
Employee attrition is influenced by multiple interconnected factors rather than a single cause
Dashboard Features
Interactive slicers and filters
KPI tracking
Attrition analysis by department, age group, income band, overtime, and job satisfaction
Employee retention insights and recommendations
Tools Used
Power BI
Power Query
DAX
Data Visualization
HR Analytics
Business Impact

The dashboard helps identify high-risk employee segments and supports data-driven retention strategies to improve workforce stability and reduce employee turnover.
